# Slideshow fonts

## Included font

`7segment.ttf`: 7-Segment (PostScript name Segment7), by Jan Bobrowski.
Copied from the user's Windows installation. Original metadata states SIL OFL.
The original font is unmodified; see `7segment-OFL.txt` for the licence text.
Author and download: https://torinak.com/font/7-segment

## System fonts

The default title uses Segoe Script from Windows. The application can register
that local system font and Segoe UI for offscreen rendering, but does not copy
or bundle either font file. Other installed fonts are selectable in the editor.
Commercial font files are not included. Add only fonts you are permitted to
redistribute when importing files into this repository.
